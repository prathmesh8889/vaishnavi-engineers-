# Vaishnavi Engineers — Food Processing Machines

A responsive static multipage website rebuilt to follow the supplied website screen-recording: clean white layout, yellow calls to action, dark navy feature section, machine cards, mobile navigation and WhatsApp enquiries.

Real machine-photo crops from the supplied Vaishnavi Engineers reference artwork are embedded in `machine-photos.css`, so the temporary reference upload and screen-recording are not needed as website assets.

## Pages
- `index.html` — Home
- `products.html` — Food processing machine catalogue
- `about.html` — About Vaishnavi Engineers
- `services.html` — How to start a machine enquiry
- `projects.html` — Food applications
- `contact.html` — Contact and WhatsApp enquiry form

## Run locally
Open `index.html` in a browser. No build step or backend is required.

## Enquiry behaviour
- Phone / WhatsApp: +91 70839 64413 (as shown in the supplied reference video)
- The contact form opens a prefilled WhatsApp message for the visitor to review and send.
- This static website does not store form submissions.
- Exact machine specifications, pricing and further company details are not invented; visitors are directed to enquire.

## Deploy
Import this repository into Vercel as a static site. Leave the build command empty and use the repository root as the output directory.
